Starting verison 19, Angular has a different way of integrating components like Drugst.One. First of all, follow basic setup steps. To allow the use of the custom component tag, the schemas entry has to be extended by adding CUSTOM_ELEMENTS_SCHEMA to the list, just not anymore in the module.ts file, but in the respective component file, e.g., drugstone-component.ts Component description: This configuration should be enough to now use the Drugst.One plugin as in any other framework.
