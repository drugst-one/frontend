Drugst.One DREAM introduces several new features available in version 2 that enhance the functionality of the plugin to offer disease module refinement. Below is an overview of these features and how to enable them in your configuration.

Feature Description Configuration
File Upload Upload network files directly into Drugst.One as .sif, .csv, .graphml or .gt file. showNetworkMenuButtonUpload: true
Community Detection Identify communities within the network using clustering algorithms i.e. Leiden and Louvain clustering. Add 'clustering' to 'showAdvAnalysisContent' array. Add 'clustering' key with ['louvain-clustering', 'leiden-clustering'] to 'algorithms' object.
Pathway Enrichment Perform pathway enrichment analysis to explore potential biological pathways associated with selected genes. Nodes from the pathways can be added to the newtork. Add 'pathway-enrichment' to 'showAdvAnalysisContent' array. Add 'gene' key with ['pathway-enrichment'] to 'algorithms' object.
First Neighbors Add all directly connected nodes to the input network based on the PPI. Add 'first-neighbor' to 'drug-target' array in 'algorithms' object.
Network Modification Allow real-time modification of the network by deleting/adding nodes. showEditNetwork: true
Pruning Filter the network based on properties as e.g. the SPD value. showPruning: true, calculateProperties: true
SVG Export Export network as a .svg file. showNetworkMenuButtonExportGraphml: true
Cellular Components Layout Visualize the cellular components of the network in a hierarchical network layout. showNetworkMenuButtonLayout: true
Logger Enable logging to track network modification and analysis. The downloaded logs can be used for reproducing results later. showLogger: true
Reviewed Proteins Filter to show only reviewed proteins. reviewed: true/false
Approved Drugs Filter to show only approved drugs. approvedDrugs: true/false
ID Space Chooser Allow users to choose the display Id space for the proteins/genes. showNetworkMenuButtonLabelIdspace: true, label: symbol/entrez/uniprot/ensembl
Overlay Directed Edges Show directed edges overlay from OmniPath on the network. showNetworkMenuButtonOverlayDirectedEdges: true
Selection Multi Drag Enable multi-drag of all selected nodes: e.g. drag a cluster for clearer layout. showNetworkMenuButtonSelectionMultiDrag: true

You can try out these configuration options in the playground tab to update your config object to enable Drugst.One DREAM.
